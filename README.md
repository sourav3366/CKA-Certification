# 🧑‍💻 Certified Kubernetes Administrator (CKA) – Complete Notes

These are my personal, topic-wise notes for the **Certified Kubernetes Administrator (CKA)** exam.  
The purpose of these notes is to keep everything:

✔ Short  
✔ Practical  
✔ Command-focused  
✔ YAML-focused  
✔ Easy to revise quickly  

Every topic follows the official **CNCF CKA Exam Syllabus** and is organized for fast revision before the exam.

- To quickly revise key Kubernetes concepts
